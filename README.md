# Superstore MIS Analysis Dashboard

## Project Overview
This project analyzes Superstore sales data using Excel, SQL, and Power BI to identify sales trends, product performance, customer behavior, and regional profitability.

## Tools Used
-Microsoft Excel
-MySQL
-Power BI
-DAX

## Business Objectives
-Analyze sales and profit performance
-Identify top-performing products and customers
-Detect loss-making categories
-Evaluate regional performance
-Monitor key business KPIs
