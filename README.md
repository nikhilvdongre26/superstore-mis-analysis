# Superstore Sales & MIS Performance Analysis

## Project Overview

This project analyzes Superstore sales data using Excel, MySQL, and Power BI to identify sales trends, product performance, customer behavior, and regional profitability.

The dataset was first cleaned and validated in Microsoft Excel, where data quality checks, shipping analysis, and derived business metrics were created. The cleaned dataset was then analyzed using SQL and visualized through an interactive Power BI dashboard.

## Project Highlights

- Analyzed 9,994 sales transactions.
- Generated $2.30M in sales and $286K profit.
- Built a 3-page interactive Power BI dashboard.
- Performed SQL-based sales and profitability analysis.
- Identified loss-making categories and top-performing regions.

## Data Preparation & Cleaning

The dataset was cleaned and validated in Microsoft Excel before analysis.

Activities performed:

- Checked for duplicate records.
- Validated missing values and data consistency.
- Corrected invalid shipping dates.
- Calculated Shipping Days.
- Created Order Year, Order Month, and Quarter fields.
- Calculated Profit Margin %.
- Performed data quality checks using Excel formulas and filters.

## Conclusion

The analysis revealed that Technology was the most profitable category, while Furniture generated significantly lower margins. California emerged as the highest-performing state, and the West region contributed the strongest overall business performance. The dashboard enables management to monitor KPIs, identify growth opportunities, and address loss-making segments.
